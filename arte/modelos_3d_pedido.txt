# 157 pedidos - MODELOS 3D para Blender (2026-11-08)
# Para ChatGPT con Blender: un modelo por bloque MODEL_REQUEST. Prioridad sugerida: las unidades únicas,
# después infantería, tanque medio, caza y destructor de cada nación, y el resto.
# Tanque moderno, pesado y superpesado NO van: están bloqueados como unidades únicas.
# ESPECIFICACIONES TÉCNICAS (para todos los modelos)
# - Programa: Blender, exportado con el exportador de Paradox (io_pdx_mesh / "PDX Blender Tools") a .mesh (+ .anim).
#   Entregar también el .blend y una vista previa .png de 3/4.
# - Escala y orientación: las de un modelo de unidad de Hearts of Iron IV (mirando hacia +Y/adelante como los del
#   juego); un tanque de unos 7 m de largo, un soldado de 1,8 m. Si dudás, que coincida con un tanque del juego.
# - Polígonos: soldados 1.500-3.000 tris cada grupo (3 figuras), vehículos 3.000-6.000, aviones 2.000-4.000,
#   barcos 6.000-12.000. Pocos materiales (uno solo idealmente).
# - Texturas .dds: <nombre>_diff (color, con desgaste y suciedad pintados, NO colores planos), <nombre>_normal y
#   <nombre>_spec; 1024x1024 para barcos y unidades únicas, 512x512 para el resto. Sombreador: PdxMeshStandard.
# - Animaciones (si se puede): idle, move y attack (y die para la infantería). Si no, rígido: igual sirve.
# - Archivos: gfx/models/units/<id>/<id>.mesh + texturas; gfx/entities/<id>.asset con la entidad <TAG>_<tipo>_entity
#   (por ejemplo EFE_light_armor_entity, NRE_infantry_entity, HSN_destroyer_entity). Yo los conecto al juego.
# - Estilo: año 2100, tecnología de después del Gran Desarme (cañones de riel, armas de pulso, misiles, drones,
#   motores de hidrógeno y pila de combustible, blindaje cerámico y compuesto). Cada nación con SU identidad
#   (abajo); que un tanque del EFE nunca se confunda con uno de la ASC. Nada de 1940.
